## Changes

Add Command Palette commands to select a private API-key file or clear the remembered selection. Remember the absolute path locally without Settings Sync or workspace overrides, load it immediately, and retain saved-key priority with an actionable notice. Validate permissions and contents, preserve the previous selection on failure, and protect selected/default paths, resolved targets, and aliases from completion context. See ADR-048.

## User test

Install the VSIX, run **Glide: Select API Key File**, and select a file containing only the key on its first non-empty line. On macOS/Linux, its resolved target must have private permissions, such as `0600` or `0400`. If a saved key is present, use the confirmation's **Remove Saved API Key** action to switch to the file. Run **Glide: Test Connection**, then reload VS Code and test again to confirm the remembered path. **Glide: Clear API Key File** restores the default location without deleting a credential.
