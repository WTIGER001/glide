## Blocking boundary failure

Reproduction in `src/benchmark/regressions.ts`:

```text
prefix:    function f() {\n
insertion: if (ok) {\n  run();\n}
suffix:    \n}
```

The insertion's final `\n}` closes the generated inner block. The suffix's `\n}` closes the already-open outer function. `safeSuffixOverlap()` currently treats the matching newline/brace as sufficient evidence of echo, removes the required inner brace, and permits a stream early stop at that point. The surrounding reconstructed program then lacks a closing brace. Non-whitespace overlap is not a sufficient boundary proof.

Next GL-02 work should preserve this legitimate insertion, handle actual echoed suffix text conservatively, test punctuation inside strings/comments and indentation variations, and replay split text/byte chunks so a midstream match cannot manufacture a completed response. Do not fix this solely by asserting a broader overlap heuristic is safe. Keep it as a development regression; no live holdout response was used to discover it.

## Limits and next session

The corpus is small and synthetic. Several values and identifiers are underdetermined from the available prefix/suffix, so the removed original is not necessarily the uniquely best suggestion. There are only seven explicit alternatives. Novel generated programs are marked unverified, with optional parse diagnostics; they are never executed on the host. Data equality can recognize YAML/JSON formatting alternatives, but it does not prove a configuration is operationally useful. A future live report must review novel valid outputs and state its adjudication rule.

This harness isolates the current prompt, Responses client, and output processor. It does not model editor scheduling, eligibility, bounded context extraction, cache reuse, physical Tab presses, or human distraction. The two cursor states per family are correlated; report family-level uncertainty in comparisons. No prompt has been tuned against development or holdout model responses. GL-07 still needs interleaved experiment arms, a declared hypothesis/budget, repeated development trials, and a frozen baseline before selecting finalists for holdout.

Continue with **GL-02 boundary follow-up using Astra High**, then **GL-07 using Astra High**. No higher thinking level is justified by current evidence. ADR-036 and the action plan record this handoff and the expanded language coverage.
