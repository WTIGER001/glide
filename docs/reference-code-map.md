## Fast reading order

For an engineer implementing Glide, the highest-value reading order is:

1. Twinny `CompletionProvider`, `CompletionStream`, and `getSuggestionContinuation`.
2. Tabby agent `generateCompletions`, `CompletionDebouncer`, cache forwarding, and postprocess order.
3. Continue `HelperVars`, `ContextRetrievalService`, `CompletionStreamer`, and stream transform pipeline.
4. The reference projects' related tests, not their chat/agent/provider UI layers.
